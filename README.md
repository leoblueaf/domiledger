# DomiLedger website

Static site for https://leoblueaf.github.io/domiledger/ (privacy policy, support, terms, homeowner guides).

- Edit page content in `pages/`, then run `python build.py` to regenerate the `.html` files at the root.
- Set the support email once in `build.py` (`SUPPORT_EMAIL`) and rebuild.
- Publish: GitHub repo `domiledger` (public) -> Settings -> Pages -> Deploy from branch `main`, folder `/ (root)`.
